# 発掘LAB Price Engine
Version: 2.0
Status: Stable
Last Update: 2026-07-09

---

# 目的

発掘LABは価格更新回数を増やすことを目的としない。

目的は

「必要な作品だけ、必要なタイミングだけ更新する」

ことである。

価格取得回数を最小化しながら最新価格を維持する。

---

# 責務

## DMM API

作品情報専用。

取得対象

- タイトル
- 女優
- メーカー
- シリーズ
- ジャンル
- レビュー
- レビュー件数
- 発売日

価格取得は禁止。

---

## Playwright

価格取得専用。

取得対象

- 販売形式
- 通常価格
- セール価格
- 割引率

作品情報取得は禁止。

# 発掘LAB思想

価格取得を最小化する。

必要な作品だけ取得する。

必要なタイミングだけ更新する。

価格取得と作品情報取得は責務を完全分離する。

完成済みモジュールは極力変更しない。

新機能は追加によって実現する。

# 発掘LAB 作品同期仕様（Ver2）

## 基本思想

作品が増える入口は「新作」のみとする。

作品情報は DMM API が責務を持ち、
価格情報は Playwright が責務を持つ。

責務は混在させない。

---

# 新規作品登録

対象

・新作一覧のみ

処理

Playwright
↓
新作一覧取得
↓
works に存在確認
↓
未登録のみ DMM API
↓

↓
Playwright 初回価格取得
↓
stage = NEW

---

# 準新作

新規登録しない。

↓

SEMI_NEW

---

# 旧作

新規登録しない。

SEMI_NEW 一覧から消えた作品は

OLD

へ変更する。

---

# セール

セール作品は新規登録しない。

works に存在する作品のみ価格更新する。

存在しない作品は無視する。
