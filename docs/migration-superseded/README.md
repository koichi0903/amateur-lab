# Superseded migration source archive

These SQL files preserve historical source paths removed from `supabase/migrations` during the approved migration reconciliation. They are audit copies only and must not be applied. Supabase's active migration directory remains `supabase/migrations`.

Each SQL file preserves the source path recorded in `manifest.csv`: 54 from the current branch's HEAD, five from `HEAD^`, two from commit `c8e6cc3204939470f23ca27eed325942397c7dfa`, two from commit `131a88b22efaac3f890c092d40ebf4138590a929` (the maker/genre indexability and pagination change), and one from `origin/main` commit `2696cec7d245cadc099dde3eb538523134b7aceb`. The manifest records the archived checkout bytes' SHA-256 and the corresponding Git blob ID after repository clean filters. Checkout line endings may differ with Git settings such as Windows `core.autocrlf`; use the blob ID to verify the source object and SHA-256 to verify the archived copy. Of the 64 archive files, 63 have a same-slug active counterpart; 61 match after line-ending normalization and SQL token comparison. Two differ from their active counterparts, and one has no active counterpart. These comparisons do not establish equality with the database's executed SQL.
